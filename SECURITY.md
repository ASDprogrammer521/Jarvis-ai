## 🚨 Reporting a Vulnerability

We take the security of **Jarvis-AI** very seriously. If you discover a security vulnerability, please help us by disclosing it responsibly.

### 🛑 Please DO NOT:
* Open a public GitHub Issue for security vulnerabilities (as this exposes the flaw to everyone before it's fixed).

### ✅ How to Report:
* **Private Vulnerability Disclosure:** You can report security issues privately via GitHub's security advisory feature (Go to **Security** tab -> **Advisories** -> **Report a vulnerability** in your repository).
* **Direct Contact:** Alternatively, you can reach out via our [Discord Server](https://discord.com/invite/r5q93NpRPt) and contact the repository maintainer directly.

### ⏱️ What to Expect:
* **Acknowledgment:** You will receive an initial response acknowledging your report within **48 hours**.
* **Updates:** We will provide regular updates on our progress regarding the vulnerability fix and status evaluation.
* **Resolution:** Once the vulnerability is confirmed and patched, we will credit you in the release notes (unless you prefer to remain anonymous).
